---- [3] float -> int (overflow) ----
Before (float)  : 10000000000.00
After  (int)    : -2147483648   <-- WRONG / undefined behaviour

---- [4] string -> numeric (atoi, unchecked) ----
Before (string) : "12abc"
After  (int)    : 12   <-- silently ignored trailing 'abc'

Before (string) : "hello"
After  (int)    : 0   <-- WRONG, no error reported, looks valid

Before (string) : "99999999999999999"
After  (int)    : 1569325055   <-- WRONG, overflowed silently

================================================================
 All conversions above completed WITHOUT any error checking.
 Every '<-- WRONG' line is a bug a real program could ship
 with no compiler error and no runtime crash.
